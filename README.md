# tallyline

Tally digests and line fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/tallyline/

## Install / run

```bash
git clone https://github.com/theworker02/tallyline.git
cd tallyline
node src/cli.js
node --test
```
